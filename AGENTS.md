## Astro

This is an Astro 7 static site. Read `docs/` before changing product, design, or architecture decisions.

Astro requires Node 22.23.4 or newer. Prefix every Node/npm/npx command with:

```sh
PATH=/home/jysim/.nvm/versions/node/v22.23.5/bin:$PATH
```

Use `npm run dev`, `npm run check`, `npm run build`, `npm run preview`, and `npm run validate` from the project root.
