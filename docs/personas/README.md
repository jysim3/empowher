# Who EmpowHER Sydney is for

One page per person or role the public website is built for. A persona round reads this index, selects affected personas, and plays each from its page.

- Persona lines have the exact shape `[Title](slug.md) · who: … · theirs: … · words: direct | relayed`; code reads them.
- `kit.json` declares this app to the tracked chat hook.
- Nobody proofreads persona pages. Code logs words and a rewrite chat folds patterns in; working sessions never edit them.
- Only public-site information and habits or words relayed by the developer may appear. No names, numbers, addresses, tokens or secrets.
